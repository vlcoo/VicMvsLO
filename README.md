A carefully crafted mobile port of 2.0 NSMB - Mario vs Luigi Online.

This port adds on-screen controls to the game, with many settings for customizing their appearance and behaviour. We also offer builds for Android and iOS!

Apart from that, the defining features of vanilla remain.
